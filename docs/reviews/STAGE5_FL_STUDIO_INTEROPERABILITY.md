## Import procedure

1. Start the recorded FL Studio version and create a blank project.
2. Use FL Studio's current MIDI import command (normally **File > Import > MIDI**). Record the exact menu/command if the version presents a different path.
3. Select `stage-5c1-interoperability.mid`. Record every import dialog option and the result; do not infer an option that is not displayed.
4. Leave the imported project otherwise unchanged. Inspect the Playlist/Piano Roll and channel/track names, then play from the beginning.
5. Complete the observations below. If a value is hidden, transformed, or not exposed by FL Studio, record `OBSERVED`, `NOT DIRECTLY VERIFIABLE`, or `FAIL` with an explanation rather than forcing `PASS`.
6. Save screenshots or comparison exports using the evidence template and retain the original fixture hash.
